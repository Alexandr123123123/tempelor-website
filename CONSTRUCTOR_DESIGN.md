# Конструктор Tempelor – подробное описание реализации

## Общий обзор

В проекте **Tempelor** конструктор (или редактор) реализован в файле `src/widgets/about/About1/ui/About1.jsx` и сопровождающих CSS‑файлах. Это интерактивный редактор, в котором пользователь может **перетаскивать**, **масштабировать**, **поворачивать** и **управлять** набором карточек (текстовых, изображений, фото). Основные задачи:

1. **Поддержка адаптивных макетов** – в зависимости от ширины окна подбирается заранее определённый набор координат/размеров (layout‑объекты).  
2. **Гибкое управление контролами** – кнопки масштабирования, изменения Z‑index, переключения snap‑направления и т.д. могут располагаться слева или справа от карточки.  
3. **Сохранение состояния** – позиции, размер и ориентацию карточек можно экспортировать/загрузить.  
4. **Минимальное вмешательство в скролл** – контейнер `chaoticContainer` имеет `overflow: visible`, а `.about` также позволяет вылезать элементам‑контроллерам наружу.

## Ключевые файлы и их роль

| Файл | Что делает | Основные элементы |
|------|------------|-------------------|

## Как работает конструктор шаг за шагом

1. **Определение текущего макета**
   ```js
   const getCurrentLayout = () => {
     const w = window.innerWidth;
     if (w > 1300) return layout1363;
     if (w > 1100) return layout1170;
     if (w > 800)  return layout969;
     if (w > 600)  return layout700;
     if (w > 528)  return layout600;
     if (w > 450)  return layout528;
     if (w > 370)  return layout450;
     return layout370;
   };
   ```
   При монтировании компонента вызывается `setLayoutData(getCurrentLayout())`, что заполняет состояние координатами, соответствующими текущей ширине окна.

2. **Рендеринг карточек**
   ```jsx
   {Object.entries(layoutData).map(([id, props]) => (
     <DraggableCard
       key={id}
       id={id}
       {...props}
       onUpdate={handleCardUpdate}
     />
   ))}
   ```
   Каждый объект макета (например, `headerCard`, `card1`, …) передаётся в `DraggableCard` как набор пропсов (`x`, `y`, `rotate`, `zIndex`, `width`, `height`, `snap`).

3. **DraggableCard**
   - **Перетаскивание** реализовано через `motion.div` с `drag` и `dragConstraints={{ left: 0, right: 0, top: 0, bottom: 0 }}` (контейнер без ограничений).
   - **Поворот** задаётся CSS‑переменной `--base-rot`/`--hover-rot` и применяется через `transform: rotate(var(--base-rot))`.
   - **Контролы** (кнопки `z+`, `z-`, `size`, `snap`, `↔`) располагаются в абсолютных позициях (`.zControls`, `.sizeControls`). При включении `controlsLeft` классу карточки добавляется `.controlsLeft`, меняя `left/right` у контролов.
   - **Сохранение изменений** – при окончании перетаскивания вызывается `onUpdate(id, newProps)`, который обновляет `layoutData` в родителе.

4. **Управление высотой контейнера**
   - В `About1.module.css` класс `.chaoticContainer` имеет `height: 1000px` (увеличено из‑начального 680px). Это гарантирует, что при малой ширине (например, 370 px) все карточки помещаются и не обрезаются.

5. **Панель редактора**
   - Фиксированная в правом нижнем углу панель (`.editorControls`) позволяет **сохранять**/**загружать** макет, **сбрасывать** состояние, **массив extra‑карточек** и **скрывать**/`minimize` редактор.
   - Кнопка «Load Layout From Below» (последний запрос) копирует текущие позиции из живой страницы в `layoutData`.

## Расширенные возможности

- **Snap‑поведение** – у карточек может быть `snap: 'left' | 'right' | null`. При `snap` контролы «залипа́ют» к выбранной стороне, а позиционирование карточки корректируется при смене направления.
- **Экспорт/Импорт** – `layoutData` можно сериализовать в JSON и сохранять в `localStorage`/сервер. При загрузке JSON массив заменяется новым набором координат.
- **Responsive breakpoints** – добавлены layout‑объекты для **1363, 1170, 969, 700, 600, 528, 450, 370** px, каждый из которых хранит оптимальные позиции и размеры, полученные из предоставленных скриншотов.
- **Контролы переключения** – кнопка `↔` (toggle) меняет состояние `controlsLeft`, что полезно, когда карточка у правого края и кнопки прячутся за экран.

## Как добавить новые карточки / изменить макет
1. **Создать запись в нужном layout‑объекте** (например, `layout700`). Указать `x`, `y`, `width`, `height`, `rotate`, `zIndex`, `snap` и, при необходимости, `type: 'photo'`.
2. **Обновить `getCurrentLayout`**, если добавлен новый брейкпоинт.
3. **При необходимости добавить стили** в `About1.module.css` (например, новые размеры для `.cardX`).
4. **Перезапустить** dev‑сервер (`npm run dev`) и проверить визуально.
